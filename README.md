## How to Use

1. **Save the code**
   Download or clone the repository and place the Python file in a folder on your system.

2. **Run the program**
   Open a terminal in that folder and run the script using Python:

   ```bash
   python filename.py
   ```

3. **Enter the image path**
   When prompted, provide the **valid path of a colored image** on your system.

4. **Choose the operation**
   Enter one of the following options when asked:

   * `show` → To display the grayscale image
   * `save` → To save the grayscale image
   * `show_save` → To display and save the grayscale image

5. **Provide save location (if saving)**
   If you choose `save` or `show_save`, enter a **valid file name or path** where the grayscale image should be saved.
